# 日本語学術論文の執筆・推敲

日本語学術論文を、論理的で読みやすい高品質な文章に改善する。

## 処理フロー（4段階）

### 1. 事前確認

以下を入力や文脈から確認する。不明点が意味や修正範囲に影響する場合だけユーザーへ質問する。通常の校正は原文の主張・用語・構成を維持して進め、文字数制限など未指定の条件は追加しない。

- **修正範囲**: 大幅な文章執筆 or 文章校正のみ
- **専門分野**: 用語の適切性確認
- **文字数制限**: 有無と具体的な上限
- **特記事項**: 論文のどの章の執筆かなど

### 2. 文章分析

入力文を以下の観点で評価する。

```
  "段落構造": "良好/要改善/不適切",
  "論理的一貫性": "明確/曖昧/矛盾",
  "学術的文体": "適切/要調整/不適切",
  "主な問題点": ["問題1", "問題2", "問題3"]
```

### 3. 段階的改善

以下の順序で修正する。

数値、引用、因果関係、主張の強さは原文どおり保持する。根拠の追加が必要な箇所は創作せず、不足を指摘する。

1. 論理構造の整理
2. 段落の適切な分割・統合
3. 学術的表現への修正
4. 文章間の内容のつながり、適切な接続詞の確認
5. 書式の統一

### 4. 品質確認

最終チェック項目:

- 一段落一主題の原則
- 段落間の論理的つながり
- 適切な接続表現
- 学術的語調の一貫性

## 書式ルール

### 基本ルール

- **句読点**: 生成する本文では「。」→「．」、「、」→「，」
- **文体**: である調で統一
- **段落**: 主題ごとに改行
- **水準**: 大学院生レベルの文章

### 良い例

```
学術論文における論理構造は，読者の理解を促進する重要な要素である．特に，段落内の結束性と段落間の連続性が適切に保たれることで，論証の説得力が大幅に向上する．
このような構造的特徴は，先行研究においても一貫して重要性が指摘されている．例えば，Smith（2023）は論理的な文章構成が読者の認知負荷を軽減することを実証している．
```

### 避けるべき例

```
学術論文では論理構造が大事です。でも、段落の構成がよくないとダメですね。それから接続詞の使い方も注意しましょう。
```
