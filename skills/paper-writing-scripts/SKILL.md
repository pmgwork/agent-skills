# 日本語学術論文の執筆・推敲

日本語学術論文を、論理的で読みやすい文章に改善する。

## 事前確認

以下を入力や文脈から確認する。不明点が意味や修正範囲に影響する場合だけ質問する。通常の校正は原文の主張・用語・構成を維持して進め、文字数制限など未指定の条件は追加しない。

- **修正範囲**: 大幅な執筆か、校正のみか
- **専門分野**: 用語の適切性の確認
- **文字数制限**: 有無と上限
- **特記事項**: どの章の執筆かなど

## 改善

数値、引用、因果関係、主張の強さは原文どおり保持する。根拠の追加が必要な箇所は創作せず、不足を指摘する。以下の順で修正する。

1. 論理構造の整理
2. 段落の分割・統合（一段落一主題）
3. 学術的表現への修正
4. 文・段落間のつながりと接続表現の確認
5. 書式の統一

## 書式ルール

- **句読点**: 生成する本文では「。」→「．」、「、」→「，」
- **文体**: である調で統一
- **段落**: 主題ごとに改行
- **水準**: 大学院生レベルの文章

```
学術論文における論理構造は，読者の理解を促進する重要な要素である．特に，段落内の結束性と段落間の連続性が適切に保たれることで，論証の説得力が大幅に向上する．
このような構造的特徴は，先行研究においても一貫して重要性が指摘されている．例えば，Smith（2023）は論理的な文章構成が読者の認知負荷を軽減することを実証している．
```
