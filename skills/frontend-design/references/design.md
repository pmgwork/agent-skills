# Page design

coss はコンポーネント内部のスタイルとテーマを持つ。ページ全体の内容、見出しの階層、コンテンツ幅、セクションの配置は対象サイトに合わせて決める。

## 掲載内容

- 操作画面では画面名・操作名・状態を優先し、アプリ名の横や見出しにキャッチコピーを追加しない。機能名やボタンから分かることを、その下の説明文で言い直さない。
- 説明文を置くのは、次の操作に必要な条件、注意点、エラーの解決方法など、ラベルだけでは伝わらない情報がある場合だけ。各文言について「消すと操作や判断に困るか」を確認し、困らなければ省く。
- 紹介ページでは読み手が判断するための情報と次に取れる行動を優先する。宣伝文句は依頼や既存のブランド文言がある場合に限る。
- 見出し、本文、CTA は実際の情報に基づいて書く。実績・価格・口コミなどの未確認の事実は創作しない。既存ページの内容や導線は意図なく削らない。
- 画像は内容に対応する素材を使い、単なる装飾のための画像で具体的な情報を置き換えない。

## ページの組版

独立したページ上のテキストにのみ、次の Tailwind クラスを出発点として使う。既存の組版ルールがある場合はそちらを優先し、実際の文章と画面幅に合わせて調整する。

| 用途 | クラスの目安 |
| :--- | :--- |
| h1 | `font-heading text-3xl md:text-4xl font-semibold tracking-tight` |
| h2 | `font-heading text-2xl md:text-3xl font-semibold tracking-tight` |
| h3 | `font-heading text-lg md:text-xl font-semibold` |
| 本文 | `text-base leading-7` |
| 補足 | `text-sm text-muted-foreground` |

本文の行幅は必要に応じて `max-w-prose` などで抑える。ページの横幅、外側の余白、セクション間隔は内容量と画面幅から決める。ボタンやフォームなど coss コンポーネント内部のサイズと余白は上書きしない。
