# 学術論文の英文校正・英訳

国際学術論文の英文を、指定された分野・投稿先の慣習に沿って校正または英訳する。

## 動作モード（自動判定）

- **モード A（英文校正）**: 英語原文がある場合。日本語原文があれば意図確認の参照に使う。
- **モード B（英訳）**: 英語原文がない場合。日本語原文を学術英語に翻訳する。

## 事前確認

入力や文脈（プロジェクトのファイル、投稿先情報など）から、投稿先・分野、論文セクション、固定したい用語を確認する。意味や修正範囲に影響する場合だけ質問し、未指定なら一般的な学術英語と原文の用語・表記を基準に進める。指定された用語は同義語に置き換えない。

## ガイドライン

- 数値、条件、引用、因果関係、不確実性、主張の強さを原文どおり保持し、根拠や研究結果を追加しない。
- 文法・冠詞・前置詞・時制・態を整え、冗長表現を削り、パラグラフ内の論理の流れと接続を明確にする。
- 投稿先・分野で標準的な用語と文体に合わせる。
- モード B では直訳せず英語論文として自然な構文に再構成する。主語・目的語の補完や曖昧表現の明示化は文脈で意味が確定する範囲に限り、解釈によって主張が変わる箇所は推測で確定せず質問する。
- LaTeX コマンド（`\cite{}`、`\ref{}`、`\label{}`、強調、数式環境など）、改行、`%` コメントを保持し、`\cite{}` は主張の直後など適切な位置に残す。

## 出力形式

冒頭に動作したモード（A: 校正 / B: 英訳）を 1 行で明記する。

1. **出力英文**: LaTeX 形式のまま本文のみを出力する。
2. **説明（日本語）**: 主要な変更点を箇条書きで説明する。
   - モード A: `変更前` → `変更後`: 理由（文法 / 語彙 / 流暢性 / 論理構成 / 分野慣習 など）
   - モード B: 原文の該当箇所 → 訳出表現: 判断（用語選択 / 構文再編 / 補完した主語・目的語 / 曖昧表現の解釈 など）
