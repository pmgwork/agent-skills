# 学術論文の英文校正・英訳

国際学術論文の英文校正・英訳を、指定された学術分野・投稿先の慣習に沿って行う。原文の意図を正確に保ちながら、自然で洗練された学術英語に仕上げる。

## 動作モード（自動判定）

- **モード A（英文校正）**: 英語原文が提供されている場合。英語原文を学術的に校正する。日本語原文があれば意図確認の参照として使う。
- **モード B（英訳）**: 英語原文がない場合。日本語原文を学術論文として通用する英語に翻訳する。

## 事前に確認する情報

以下がユーザーの入力や文脈（プロジェクトのファイル、投稿先情報など）から分からない場合は確認する。

1. **学術分野・投稿先**: 投稿予定の学会・ジャーナル名と分野（例: 機械学習 / NeurIPS、HCI / CHI）。
2. **論文セクション**: Abstract / Introduction / Method など。
3. **用語の指定**: 必ず使用すべき用語（訳語を固定したい専門用語）の有無。指定された用語は他の同義語に置き換えない。

## ガイドライン

### 言語面（モード A・B 共通）

- 学術論文に適した語彙・表現（フォーマル、客観的、簡潔）を使用する。
- 文法・スペル・冠詞・前置詞の誤りを修正する。
- 一貫した時制と、能動態/受動態の適切な使い分けを確認する。
- 冗長表現を排し、簡潔かつ明確に改善する。
- 自然で流暢なネイティブレベルの文章に整える。

### 英訳時の追加指針（モード B）

- 直訳ではなく、英語論文として自然な構文・語順に再構成する。
- 日本語特有の曖昧表現は、文脈から最も妥当な解釈を選んで明示化する。
- 主語・目的語が省略されている場合は適切に補う。
- 一文が長すぎる場合は、論理を保ったまま分割する。
- 投稿先の分野で標準的な専門用語を選択する。

### 論理・構成面

- パラグラフ構造と論理の流れを改善する（topic sentence → support → transition）。
- 接続詞・談話標識を適切に配置し、論理関係を明示する。
- 各文の論理的つながりを強化する。

### 分野・投稿先への適合

- 指定された学会・分野の慣習的な表現・用語を採用する。
- 専門用語は分野の標準表記に統一する。
- 当該分野で好まれる文体（簡潔さ重視 / 厳密さ重視など）に合わせる。

### LaTeX 形式の保持

- `\cite{}`, `\ref{}`, `\label{}`, `\textit{}`, `\textbf{}`, `\emph{}`, 数式環境（`$...$`, `\begin{equation}` 等）など、すべての LaTeX コマンドを正確に保持する。
- 引用 `\cite{}` は適切な位置（主張の直後など）に残す。
- 改行・コメント（`%`）等のフォーマットも保持する。

## 出力形式

冒頭に動作したモード（A: 校正 / B: 英訳）を 1 行で明記する。

### 1. 出力英文

LaTeX 形式のまま、校正済み（モード A）または英訳済み（モード B）の本文のみを出力する。

### 2. 説明（日本語）

主要な変更点・翻訳判断を箇条書きで説明する。

- **モード A（校正）**: `変更前` → `変更後`: 変更の理由（文法 / 語彙 / 流暢性 / 論理構成 / 分野慣習 など）
- **モード B（英訳）**: 原文の該当箇所 → 訳出表現: 訳出の判断（用語選択 / 構文再編 / 補完した主語・目的語 / 曖昧表現の解釈 など）
