# Antigravity CLI 日本語校正

agy は校正エンジンとしてだけ使い、範囲の決定・検証・統合は自分で行う。agy は必ず `scripts/agy_fix.sh` 経由で実行し、本文はファイルで渡す（プロンプトの制約はスクリプト内にある）。導入・終了コード・実行環境の注意は `references/agy-cli.md` を参照する。

```bash
scripts/agy_fix.sh --style general --input ./draft.txt --output ./draft.fixed.txt [--model NAME] [--timeout 120]
```

## 文体プリセット（既定は general）

- **general**: 原文の文体（である／ですます）を維持し、読みやすさだけ改善
- **academic**: である調、句読点は全角「．」「，」（`$paper-writing-scripts` 互換）
- **business**: ですます調、敬語・表記ゆれを整える

対象本文がなければ提示を依頼する。プリセットや修正範囲は、意味に影響する場合だけ質問し、それ以外は既定で進める。

## 検証

agy の出力は無条件に採用しない。意味・数値・固有名詞・引用・主張の強さが変わった箇所、創作や根拠の追加、LaTeX・Markdown の破損は採用せず、必要なら範囲を狭めて再実行する。原文ファイルへの上書きは明示指示がある場合のみ行う。

## フォールバック

agy が使えない（不在・未ログイン・利用枠・タイムアウト）場合は、案内だけして待たずに自分で校正する。範囲は誤字脱字・表記ゆれ、主述・助詞の対応、文体統一、長すぎる一文の分割までとし、意味が確定しない箇所は残課題にする。

## 出力

1. **修正後文章**（コードブロック）
2. **修正ポイント**: 誤字・表記／文法・語順／文体統一／残課題（確定できなかった箇所・不足情報）
