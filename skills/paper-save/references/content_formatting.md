# 原文本文のAI整形

Docling Markdownを、意味を変えずに読みやすい論文構造へ復元する。この工程は要約や校正ではない。原文の情報、表現、図表、数式、引用を保持し、PDFレイアウト由来のノイズだけを整える。

## 固定する外枠

Abstract相当の節が存在する場合:

```markdown
## Abstract

Abstractの原文

## 原論文の最初の主要章

...
```

Abstract相当の節が存在しない場合:

```markdown
## 原論文の最初の主要章

...
```

- ノート本文にH1を作らない。タイトルはfrontmatterとObsidianのインラインタイトルに任せる。
- `原文` や `本文` のコンテナ見出しを作らない。
- Abstract相当がある場合だけ、見出しを正確に `## Abstract` として分離する。
- Abstract以外の論文内容は、原論文の主要章から直接始める。

## 原論文の章構成を保持する

- 原論文に存在する見出し名、順序、相対的な親子関係を保持する。
- `Introduction`、`Related Work`、`Method` などの標準見出しを推測で追加しない。
- 原論文の見出しを一般的な名称へ改名、統合、分割しない。
- 原論文の最上位章を `##`、その小節を `###` 以下へ相対的に正規化する。
- `References`、`Bibliography`、`Appendix` も、存在する場合だけ原論文の位置と名称で保持する。参考文献項目の内容だけは `references/reference_links.md` に従ってリンク一覧へ変換する。
- 見出しらしい文字列でも、著者名、所属、図captionは章見出しにしない。

## 除外する情報

本文から次を除外する。frontmatterやBibTeXに必要な情報は除外前に取得する。

- 重複する論文タイトル
- 著者名、所属、住所、メールアドレスのブロック
- Author Keywords、Index Terms、ACM Classificationなどの索引用情報
- copyright、permission、license、出版者の定型文
- PDFフォームやテンプレートに残った非表示・プレースホルダー文字
- ページヘッダー、フッター、ページ番号、会議名の柱

謝辞、資金情報、利益相反、データ可用性など、論文内容として明示された節は削除しない。

## 復元してよいもの

- 多段組みを論理的な読み順へ並べ直す。
- 改行や段組みで分割された文と単語を接続する。
- `&amp;` などのHTML entityを対応する文字へ戻す。
- 明白な文字間スペースの欠落、行末ハイフネーションを直す。
- Doclingが見出しとして認識し損ねた原論文の見出しを、PDF上の構造が明白な場合だけ復元する。

綴り、文法、論文著者による原文上の誤りは修正しない。判断に自信がない文章は削除や改変をせず保持する。

## 数式

Doclingが数式をUnicode数式文字や不自然な空白を含む通常テキストとして抽出した場合は、原本PDFと照合してObsidianで表示できるLaTeXへ復元する。

- 文中の数式と変数は `$...$`、独立した数式は `$$...$$` にする。
- `0 . 5`、`𝑝 < = . 003`、`𝑙𝑜𝑔 2`、`𝜂 2 𝑝` など、PDF抽出で混入した空白と分離文字を修正する。
- 小数、添字、上付き、ベクトル、演算子、不等号、単位をPDF上の表記と照合する。
- 数式番号がある場合は `\tag{n}` を保持する。
- 数値、記号、演算子を推測で補わない。PDFから確定できない式は原文のまま残し、完了報告で示す。
- 通常の英文や著者による数式表現そのものは書き換えない。

例:

```markdown
$MT = a + b\log_2(A/W + 1)$

$p \le .003$, $\eta_p^2 = .47$
```

## 保持するもの

- AbstractがあればAbstractから、なければ最初の実質的な主要章から論文末尾までの内容
- 図、caption、表、LaTeXへ復元した数式、脚注、本文中の引用番号、参考文献で挙げられた全作品
- Obsidian形式へ変換済みの全画像埋め込み
- 原文の言語と文体

要約、翻訳、説明の追加、事実の補完、文章の言い換えを行わない。参考文献一覧から書誌情報を除く処理だけは `references/reference_links.md` の明示的な例外とする。

## Figureとcaption

図は、対応する本文上の位置で必ず画像を先、説明文を後にする。

```markdown
![[assets/{SanitizedTitle}/artifacts/image_001.png]]

Figure 1: Original caption text.
```

- Doclingが `caption → 画像` の順で出力した場合は `画像 → caption` へ入れ替える。
- 複数画像が1つのcaptionに対応する場合は、対応する画像をすべて並べた後に共有captionを置く。
- captionの原文、Figure番号、本文中の参照番号を変更しない。
- 画像とcaptionの間に空行を1行入れる。
- captionを見出し、引用、画像alt textへ変換しない。
