# 参考文献の内部リンク

`References`、`Bibliography` などの参考文献一覧がある場合は、一覧全体を番号付きの作品タイトルObsidian内部リンクへ変換する。著者、年、掲載先、ページ、DOIなどの書誌情報は最終ノートの参考文献一覧へ残さない。

## 出力形式

```markdown
## References

1. [[Sanitized Work Title|Official Work Title]]
2. [[Another Work Title]]
```

- 1作品につき1つの番号付きリスト項目とする。
- 原文の参考文献番号と順序を保ち、本文中の `[1]` などと対応させる。
- リンク以外の著者、年、掲載先、DOI、注釈をリスト項目へ加えない。
- 最後のリンクと次の見出しの間に空行を1行入れる。
- リンク先と表示名が同じ場合は `[[Official Work Title]]` としてよい。
- リンク先と表示名が異なる場合は `[[Sanitized Work Title|Official Work Title]]` とする。

## リンク先

- 作品タイトルへ `references/naming.md` のSanitizedTitle規則を適用した値をリンク先に使う。
- 対応する既存ノートがある場合は、その実在するファイル名をリンク先として優先する。
- 対応するノートがなくても、将来作成されるノートへの未解決リンクとして作成する。
- 書籍、動画、Web資料、学位論文も、作品タイトルを特定できれば同じ形式でリンクする。

## 正式タイトルの決定

1. 参考文献にDOIがある場合は、出版社またはDOI登録機関の公式メタデータで正式タイトルを照合する。
2. DOIがなく公式公開ページを特定できる場合は、その正式タイトルを使う。
3. 公式情報を特定できない場合は、参考文献に記載されたタイトルを省略せず使う。
4. 作品タイトルの範囲を十分に特定できない場合は、参考文献を省略したり推測リンクを作ったりせず、登録を中止して該当項目をユーザーへ報告する。

URLの発見とページ抽出は `references/metadata.md` と同じく、Codex web search、`ax`、必要な場合のみブラウザツールの順で行う。

## 本文中の引用

本文中の `[1]`、`[2, 3]` などの引用記号は原文のまま保持する。引用記号をwikilinkへ置き換えず、Referencesの番号付きリンクと同じ番号で対応させる。
