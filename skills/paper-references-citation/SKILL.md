# 学術論文の引用文作成

特定の研究論文（抄録または本文の一部）から、日本語学術論文の「関連研究」「序論」等のセクションで使用可能な引用文を生成する。

## 事前に確認する情報

以下がユーザーの入力から分からない場合は、推測で補わず確認する。

1. **論文の内容**: 抄録、要約、または引用元として使いたい本文の該当部分。
2. **著者名**: 筆頭著者の姓（ローマ字表記）。
3. **形式**: 希望する文章の長さ（例: 1文、2文）と、強調したい研究上のポイント（例: 手法、結果、新規性）。

## 出力フォーマット

以下のテンプレートに従い、引用文を 1 つ生成する。

```
[著者名]らは，[研究の主たる貢献・手法・結果を簡潔にまとめた本文]．
```

## 文体・表記ルール

- 文体は「である」調（常体）を厳格に使用し、「です・ます」調は用いない。
- 生成する引用文の句読点は全角コンマ「，」および全角ピリオド「．」を使用し、「、」「。」は使用しない。
- 数値・英字・括弧は半角を基本とするが、文中の補足は全角括弧（）を用いる。
- 著者の引用は「[著者姓]ら」の形式で統一する（単独著者の場合も同様）。

## 内容に関するルール

- 論文の主要な貢献、採用された手法、定量的な結果（精度、改善率など）のうち、指定された観点を優先的に含める。
- 背景説明、先行研究との詳細な比較、今後の展望といった付随情報は原則として省略する。
- 元の抄録に記載のない情報を補完・推測しない。
- 専門用語は日本語訳を用い、必要に応じて括弧内に英語表記または略語を併記する（例: ブレイン・コンピュータ・インターフェース（BCI））。

## 出力時の制約

- 出力は引用文のみとし、前置き・後置きの説明文は付与しない。
- 複数案を求められた場合は、番号付きで 2〜3 案を提示する。
- 指定された文長（文数）を厳守する。
